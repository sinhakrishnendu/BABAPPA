# BABAPPA-BENCH-SIM-v1

This design defines a known-truth simulation benchmark for BABAPPA.

Truth labels are generated by the simulator and are used only during evaluation.

## Profiles

- `smoke`: 12 families
- `pilot`: 300 families
- `paper`: 5000 families
- `extended`: 20000 families

## Regimes

- `null_low_divergence`: null, low, expected in_domain
- `null_moderate_divergence`: null, moderate, expected in_domain
- `null_high_divergence`: null, high, expected borderline
- `null_extreme_divergence`: ood_null, extreme, expected out_of_domain
- `null_alignment_difficult`: null, moderate, expected borderline
- `null_short_gene`: null, moderate, expected borderline
- `null_few_taxa`: ood_null, moderate, expected out_of_domain
- `null_long_branch`: null, high, expected borderline
- `positive_weak_branch_site`: positive, moderate, expected in_domain
- `positive_moderate_branch_site`: positive, moderate, expected in_domain
- `positive_strong_branch_site`: positive, moderate, expected in_domain
- `positive_short_foreground`: positive, moderate, expected in_domain
- `positive_long_foreground`: positive, moderate, expected borderline
- `positive_sparse_sites`: positive, moderate, expected in_domain
- `positive_clustered_sites`: positive, moderate, expected in_domain
- `positive_multi_branch`: positive, moderate, expected in_domain
- `positive_alignment_difficult`: positive, high, expected borderline
- `ood_extreme_saturation`: ood_null, extreme, expected out_of_domain
- `ood_too_few_taxa`: ood_null, moderate, expected out_of_domain
- `ood_too_short`: ood_null, moderate, expected out_of_domain
- `ood_high_gap`: ood_null, moderate, expected out_of_domain
- `ood_compositional_bias`: ood_null, moderate, expected out_of_domain
- `ood_paralogy_like`: ood_null, high, expected out_of_domain
- `ood_tree_mismatch_like`: ambiguous, moderate, expected out_of_domain

## Claim Boundary

This benchmark validates BABAPPA against explicit simulated truth. codeml/HyPhy comparisons are comparator analyses, not truth labels.
